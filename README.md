# ntroll

Basically, a way to disable internet access on a per-app basis (I swear Android used to have this built in). I mainly made it (strong word) because of ads in offline Android games. I know there are similar apps already on the Play Store, but I'm not very eager to feed all my internet traffic through an unknown app (and it was also a fun test for gpt 6.1 sol and astra... insane how powerful they are, the end is near).
